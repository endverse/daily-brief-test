编码 Agent 的 Harness 设计实证研究

论文系统研究「编码脚手架（harness）」如何决定自主编码 agent 把模型能力转化为长程软件工程表现。做法是固定执行主循环，只变动规划（planning）、动作空间（action space）、上下文管理（context management）三个组件，在四个模型上做组件级对照。结论是这三者的设计往往比底层模型更能左右 agent 的最终完成率。这给自建编码类 agent 指出了明确着力点：优先打磨任务规划、工具与动作的暴露方式、上下文管理，而不是只盯着换更强的模型。
